กิจกรรม

    cookie ของบัญชี TikTok

    ดึงจาก Chrome อัตโนมัติโปรแกรมอ่าน cookie ของ tiktok.com จาก Chrome ทุกนาที

    หรืออัปโหลดไฟล์เอง

    1. ล็อกอิน tiktok.com ในเบราว์เซอร์ด้วยบัญชีของคุณเอง
    2. Export cookie เป็นไฟล์ cookies.txt (รูปแบบ Netscape)
    3. ลากไฟล์มาวางด้านล่าง หรือเลือกไฟล์

    cookie มีค่าเท่ากับรหัสผ่านบัญชี เก็บไว้ในเครื่องนี้เท่านั้น (อ่านได้เฉพาะเจ้าของไฟล์)

    ลบคลิปเก่าอัตโนมัติ

    โปรแกรมจะลบคลิป MP4 ที่เก่าที่สุดทีละไฟล์จนพื้นที่ว่างกลับมาเกินค่านี้ เช็กทุก 5 นาที จะไม่ลบคลิปที่กำลังอัด ไฟล์ย่อยที่ยังไม่ได้รวม หรือคลิปที่กำลังอัปโหลด และจะแจ้งเตือนทุกครั้งที่ลบ

    เปิดบนมือถือ

    ให้มือถือต่อ Wi-Fi วงเดียวกับคอมเครื่องนี้ แล้วสแกนด้วยกล้อง

    ลิงก์นี้มีรหัสผ่านในตัว ใครได้ไปก็เปิดหน้านี้ได้ อย่าส่งให้คนอื่น

    ตอนนี้โปรแกรมเปิดให้เข้าได้เฉพาะจากคอมเครื่องนี้ ให้รันด้วย --host 0.0.0.0 เพื่อให้มือถือในบ้านเข้าได้

    อัปโหลดขึ้น YouTube

    สถานะ
    1. เปิด Google Cloud Console แล้วสร้างโปรเจกต์ใหม่ (ฟรี)
    2. เปิดใช้ YouTube Data API v3
    3. ตั้งค่า OAuth consent screen แบบ External แล้วเพิ่มอีเมลตัวเองใน Test users
    4. ไปที่ Clients → Create client → ชนิด Desktop app → ดาวน์โหลด JSON
    5. ย้ายไฟล์ที่ได้ไปไว้ในโฟลเดอร์โปรแกรมชื่อ client_secret.json แล้วเปิดหน้าต่างนี้ใหม่

    คลิปจะขึ้นเป็น ส่วนตัว (Private) เสมอ เห็นเฉพาะคุณ โควตาฟรีของ Google อัปได้ประมาณ 6 คลิปต่อวัน การเชื่อมบัญชีต้องกดจากคอมเครื่องนี้
